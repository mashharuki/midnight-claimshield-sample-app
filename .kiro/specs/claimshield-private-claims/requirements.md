
# Requirements Document

## Project Description (Input)

福利厚生または経費ポリシーの利用者は、支出額・店舗名・レシート内容・実ウォレットアドレスを公開することなく、申請がポリシーに適合し、同じレシートを二度使っていないことを証明できない。ClaimShield は、申請者が秘密入力を端末に保持したまま適格性を ZK 証明して申請し、管理者が dApp 外での資料確認後に承認または取消を記録し、承認済み申請者が同じ秘密入力の保持を再証明して一度だけ引換済みにすることを可能にする。MVP は固定給付の資格記録に限定し、資産送付、レシート保管、OCR、KYC、端末間同期、秘密値の紛失後の復旧は扱わない。詳細な背景、デモフロー、プライバシー境界、受入要件は `docs/claimshield-requirements.md` を参照する。
